# Personal Portfolio Website

This project is a responsive personal portfolio website created for SWE 363 Assignment 1. It introduces me, presents my skills and projects, and provides a contact form.

## Features

- About Me section
- Skills section
- Projects section
- Contact form
- Responsive design for desktop, tablet, and mobile
- Dark and Light Mode toggle
- Back to Top button with smooth scrolling

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Project Structure

- `index.html` - Main webpage
- `css/styles.css` - Website styling and responsive design
- `js/script.js` - Interactive JavaScript features
- `assets/images/` - Project images
- `docs/` - Project documentation
